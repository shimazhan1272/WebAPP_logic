# ボートレースAI予想 Webアプリ

全24箇所のボートレース場に対応し、過去26万レースのデータから最尤推定された条件付きロジット（Plackett-Luce）統計モデルに基づいて、各艇の1着確率および推奨買い目（3連単・2連単・3連複）をリアルタイムに算出・表示するWebアプリケーションです。

---

## 1. アプリの特長・主要機能

- **全24レース場対応**: 桐生(01)から唐津(23)、大村(24)まで全場完全網羅。
- **当日レースの最優先取得**: 当日レース開催時は `today.json`（約3分間隔で定期デプロイ）を最優先で照会し、開催中のレース場のみを自動抽出。
- **締切・終了ステータスのリアルタイム自動更新**:
  - レース番号プルダウンに締切時刻を表示（例: `6R 16:10締切`）。
  - **締切10分前**に入ったレース番号は**赤文字**で強調表示。
  - **発売締切済み・レース終了後**のレース場は `【終了】24_大村`、レース番号は `【終了】9R` と表示。
  - ページを再読み込みすることなく10秒ごとに自動更新。
- **前付け・進入コース隊形の自動判定**:
  - スタート展示で進入が枠なりと異なる場合、「前付けあり」と進入隊形（例: `4-1-2-3-5-6`）を表示。
- **公式6枠色対応の出走艇詳細テーブル**:
  - 1白, 2黒, 3赤, 4青, 5黄, 6緑の公式枠色。
  - 支部名、級別、全国勝率、全国2連率・3連率（小数第2位）、当地2連率・3連率（小数第2位）、モーター2連率、平均ST、展示タイム。
- **スタート展示スリット隊形（SVG可視化）**:
  - 助走方向からスタートライン（ST）までの艇間隔・進入コース順をグラフィカルに図示。
- **風向・風速補正カード**:
  - 風向（1〜16、17=無風）と風速（m/s）から計算されたコース別の効果（コース平均との差）を表示。
- **フォーメーション集約買い目表示（1列表示）**:
  - `1-2-345`、`1-245-2`、`2-34-356` など、共通条件の買い目をカンマなしフォーメーションとして最小行数に集約。
  - 実買い目の混入を防ぎ、フォーメーション行ごとの点数・合算確率と、折りたたみ展開による個別買い目内訳を確認可能。
- **買い目点数プルダウン（0〜30点）**:
  - 3連単、2連単、3連複をそれぞれ0〜30点で指定。0点指定の券種は自動非表示。
- **予想モデル係数調整（スライダー）**:
  - 「当地2連率」「モーター2連率」「展示タイム補正」の3項目を -3.0〜+3.0 で微調整可能。
- **展示タイム・気象・進入コースの手動修正**:
  - 直前情報が未発表の段階でも、独自の展示タイムや進入コースを入力して即座に再試算可能。
- **PWA（Progressive Web Apps）完全対応**:
  - PC・スマートフォン（iOS / Android）でホーム画面に追加し、ネイティブアプリ感覚で利用可能。オフラインキャッシュ対応。
- **入力・設定の自動保存**:
  - 最後に選択した日付・場・レース番号、点数、スライダー値を `localStorage` に保持し、次回起動時に自動復元。

## 2. セットアップ & 実行手順

### 必要環境
- Node.js 18.0.0 以上
- npm 9.0.0 以上

### インストール & 起動
```bash
# 依存関係のインストール
npm install

# 開発用サーバー起動 (ローカル: http://localhost:3000)
npm run dev

# プロダクションビルド
npm run build

# ビルド成果物のローカルプレビュー
npm run preview
```

### GitHub Pages 等での公開手順
1. `vite.config.ts` の `base` をリポジトリ名（例: `base: '/boatrace-ai/'`）またはルートに設定します。
2. `npm run build` を実行すると `dist/` ディレクトリに静的ファイル一式が出力されます。
3. GitHub Actions または `gh-pages` コマンドで `dist` フォルダを公開ブランチ（`gh-pages`）にプッシュするだけで、Webアプリとして即座に公開できます。

## 3. データ取得の仕組みとフォールバック

本アプリは、以下の優先順位で最新の出走表・直前情報を自動取得します。

```
[当日レース]
  │
  ├─ 1. Boatrace Open API 当日データ (today.json) 【最優先】
  │     https://boatraceopenapi.github.io/api/v1/today.json
  │     ※ GitHub Actionsにより約3分間隔で定期デプロイ
  │     ※ キャッシュ回避パラメータ（_t=タイムスタンプ）および cache: 'no-store' で取得
  │
  ├─ 2. Boatrace Open API v2 プログラム & プレビュー
  │     https://boatraceopenapi.github.io/programs/v2/{YYYY}/{YYYYMMDD}.json
  │     https://boatraceopenapi.github.io/previews/v2/{YYYY}/{YYYYMMDD}.json
  │
  └─ 3. 公式サイト (boatrace.jp) 直前情報 HTML スクレイピング (フォールバック)
        https://boatrace.jp/owpc/pc/race/beforeinfo?rno={R}&jcd={場コード}&hd={年月日}
```

### boatrace.jp 取得用プロキシの設定方法
ブラウザ環境から `boatrace.jp` を直接 `fetch` すると、ブラウザの CORS（Cross-Origin Resource Sharing）制約によりブロックされます。そのため、本プロジェクトでは以下の2通りのプロキシ構成をサポートしています：

1. **Vite開発サーバーのプロキシ設定（設定済み）**:
   `vite.config.ts` 内にプロキシ設定が含まれており、`/proxy/boatrace/*` へのリクエストが `https://boatrace.jp/*` へサーバー経由で転送されます。ローカル開発時は特別な設定不要でそのまま動作します。
2. **クラウド・無料プロキシ（GitHub Pages 等の静的ホスティング用）**:
   Cloudflare Workers や Vercel Serverless Functions を用いて簡単な CORS プロキシを作成するか、`api.allorigins.win` などの無料公開プロキシをフォールバックとして利用できます。

> **直前情報が未発表の場合**:
> 展示航走前など、どのAPIからも直前情報が取得できない場合は、展示タイム補正・風補正を 0 として計算を継続します（アプリはエラー停止しません）。手動修正アコーディオンから展示タイムや進入コースを入力することで、直ちに再計算できます。

## 4. 予想モデル係数調整の使い方

「予想モデル係数調整」アコーディオンを開くと、以下の3つのスライダーが表示されます：
- **当地2連率**（基準値: 0.0035）
- **モーター2連率**（基準値: 0.0100）
- **展示タイム補正**（1コース基準値: 2.768）

### 実効係数の計算式
$$\text{実効係数} = \text{基準値} \times \left(1 + \frac{\text{スライダー値}}{3}\right)$$

- **スライダー値 0**: 基準値（過去26万レースから最尤推定されたデフォルト係数）
- **スライダー値 +3.0**: 基準値の **2倍**（その項目の影響度を倍増）
- **スライダー値 -3.0**: **0**（その項目の影響を完全に無効化）

スライダーを動かすと、ネットワーク通信を再発生させることなくブラウザ上で瞬時にオッズ・確率・買い目が再計算されます。「0に戻す」を押すといつでも初期基準値に戻せます。

## 5. 展示タイム・気象・進入コースの手動修正

「展示タイム・気象データ・進入コースの手動修正」アコーディオンでは、以下の項目を手動で書き換えることができます：
- **各艇の展示タイム**: 6.50〜7.00程度の数値を入力。全6艇分揃った時点で展示タイム補正が適用されます。
- **進入コース**: 1〜6のコースを選択。前付けや枠なり崩れの想定をシミュレーションできます。枠番より内側に入った艇には前付けペナルティ（`-0.1360 × 動いたコース数`）が適用されます。
- **風速 (m/s)**: 0〜20m。未入力または0の場合は風補正なし。
- **風向**: コード1〜16（17=無風）、追い風（コード5）、向かい風（コード13）、横風A（コード9）、横風B（コード1）などのプリセットから選択。
- **波高 (cm)**: 0〜50cm。

## 6. 買い目の見方

- **フォーメーション表記**:
  - `1-2-345`: 1着=1号艇、2着=2号艇、3着=3・4・5号艇の3点。
  - `1-245-2`: 1着=1号艇、2着=2・4・5号艇、3着=2号艇の2点（※同着除外）。
  - `2-34-356`: 1着=2号艇、2着=3・4号艇、3着=3・5・6号艇の集約。
  - **カンマなし**で直感的に表記されます。
- **確率(%)の定義**:
  - 「各買い目がその着順で入る確率（モデル推定値）」。
  - フォーメーション行に表示されているパーセンテージは、**その行に含まれる買い目の確率の合計値**です。
  - 行をクリックすると内訳が展開され、各買い目の個別確率を確認できます。

## 7. 統計予想モデルの数理・検証結果

### 7-1. モデル構造
過去 264,035 レースの結合データから、**Plackett-Luce 型の条件付きロジット**を最尤推定したモデルです。

各艇 $i$（進入コース $c_i \in \{0, \dots, 5\}$）のスコア:
$$\begin{aligned}
\text{score}_i = &\; \text{COURSE\_INTERCEPT}[c_i] \\
&+ 0.6347 \times (\text{全国勝率} - 5.5) - 0.0124 \times (\text{全国2連率} - 35) \\
&+ c_{L2}' \times (\text{当地2連率} - 35) + c_{M2}' \times (\text{モーター2連率} - 35) \\
&- \text{ST\_COEF}[c_i] \times (\text{平均ST} - 0.16) + \text{GRADE\_ADJ}[\text{級別}] \\
&- \text{EX\_COEF}'[c_i] \times (\text{展示タイム} - \overline{\text{展示タイム}}) \\
&+ \text{windTerm}[c_i] + \text{FRONT\_PENALTY} \times \max(0, \text{枠番} - c_i)
\end{aligned}$$

確率の計算:
- 1着確率: $p_i = \frac{e^{\text{score}_i - m}}{\sum_j e^{\text{score}_j - m}}$ （$m = \max_k \text{score}_k$）
- 2着・3着確率: 着順別温度パラメータ $\lambda_2 = 0.7755, \lambda_3 = 0.7003$ および着順別コースオフセット $\text{COURSE\_OFFSET2}, \text{COURSE\_OFFSET3}$ を加味した Plackett-Luce 連鎖確率。

### 7-2. 検証結果比較
2025年7月以降の検証期間（69,916レース）における評価：

| モデル | 3連単 対数尤度 | 1着 対数尤度 |
|---|---|---|
| 旧・手設定モデル | −4.155 | −1.2254 |
| 推定（風向なし） | −3.885 | −1.2167 |
| ＋風向項 | −3.884 | −1.2160 |
| **＋着順別コース補正（本アプリ仕様）** | **−3.856** | **−1.2117** |

- 旧モデル比で 3連単の対数尤度は **+0.30** 大幅に改善。
- 検証期間におけるコース別1着率の予測精度:
  - 1コース: 予測 54.9%（実績 54.7%）
  - 2コース: 予測 14.1%（実績 13.6%）
  - 3コース: 予測 12.4%（実績 12.9%）
  - 4コース: 予測 10.1%（実績 10.3%）
  - 5コース: 予測 6.0%（実績 6.1%）
  - 6コース: 予測 2.4%（実績 2.4%）
- **回収率実績**:
  - 3連単上位5点: 的中率 33.5%、回収率 76.9%
  - 2連単上位3点: 的中率 50.1%、回収率 78.7%
  - 3連複上位3点: 的中率 52.9%、回収率 78.0%
  ※ボートレースの法定控除率（払戻率約75%）の水準に一致しており、オッズを加味したプラス収支を保証するものではありません。

## 8. 免責事項
統計モデルによる参考値です。係数は過去約26万レースから推定したもので、的中を保証するものではありません。回収率は控除率の水準で、期待値の高い買い目を示すものではありません。買い目点数は各券種0〜30点まで指定できます。馬券・舟券の購入は自己責任で行ってください。
